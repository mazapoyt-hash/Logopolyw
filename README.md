# Трекер задач

Страница, куда можно записывать баги, идеи и дела вместо переписки в мессенджере.
Ничего настраивать не нужно: открывается как обычный сайт или файлом с диска.

Файлы: `index.html`, `tracker.css`, `tracker.js`.

## Что умеет

- **Задачи** — заголовок, подробное описание (шаги воспроизведения), приоритет,
  раздел, статус и срок.
- **Приоритеты** — критичный / высокий / средний / низкий. По умолчанию список
  отсортирован по приоритету, критичные сверху; кнопки ▲ ▼ на карточке меняют
  приоритет на месте.
- **Статусы** — новая, в работе, отложена, готово. Клик по квадратику слева
  переключает их по кругу; готовые задачи всегда уезжают в конец списка.
- **Сроки** — необязательная дата. Трекер сам подписывает «срок сегодня»,
  «срок завтра», «просрочено на N дней» и подсвечивает просроченные карточки.
- **Разделы** — свои категории задач вместо фиксированного списка. Заводятся
  в блоке «Разделы», там же видно, сколько задач в каждом. Удаление раздела
  не трогает задачи — они переезжают в «Другое».
- **Фильтры** — поиск по тексту, фильтры по приоритету, разделу и статусу;
  сортировка по приоритету, сроку, дате создания или статусу.
- **Счётчики** — всего, открытых, в работе, критичных открытых и просроченных.
- **Данные** — задачи хранятся в `localStorage` этого браузера. Кнопки в блоке
  «Данные» позволяют выгрузить резервную копию в JSON, загрузить её на другом
  устройстве (задачи с тем же `id` обновляются, новые добавляются) и скопировать
  текущий список готовым markdown-чеклистом — удобно вставить в issue или сообщение.

## История

Раньше в этом репозитории лежала онлайн-Монополия (`app.js`, `render.js`,
`board-data.js`, `firebase-config.js`, `style.css`). Игра удалена — её код остался
в истории git, в коммите `d71efdc` и раньше. Задачи, записанные в первую версию
трекера, переносятся в новый формат автоматически при первом открытии страницы.
