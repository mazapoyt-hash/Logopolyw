# Logopolyw

## Трекер задач и багов

`tracker.html` — отдельная страница, куда можно записывать баги и идеи вместо переписки
в мессенджере. Никакой настройки не требуется: просто откройте файл в браузере
(или зайдите на `.../tracker.html`, если проект выложен на GitHub Pages).

Что умеет:

- **Задачи** — заголовок, подробное описание (шаги воспроизведения), приоритет, раздел, статус.
- **Приоритеты** — критичный / высокий / средний / низкий. По умолчанию список отсортирован
  по приоритету, критичные сверху; кнопки ▲ ▼ на карточке меняют приоритет на месте.
- **Статусы** — новая → в работе → готово, переключаются кликом по квадратику слева.
  Готовые задачи всегда уезжают в конец списка.
- **Фильтры** — поиск по тексту, фильтр по приоритету, разделу и статусу; сортировка
  по приоритету, дате или статусу.
- **Счётчики** — всего / открытых / в работе / критичных открытых.
- **Данные** — задачи хранятся в `localStorage` этого браузера. Кнопки в блоке «Данные»
  позволяют выгрузить резервную копию в JSON, загрузить её на другом устройстве
  (задачи с тем же `id` обновляются, новые добавляются) и скопировать текущий
  список готовым markdown-чеклистом — удобно вставить в issue или сообщение.

Файлы: `tracker.html`, `tracker.css`, `tracker.js` — от игры не зависят.
